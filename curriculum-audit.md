# Curriculum and source audit

All 24 official topics are represented in the supplied source. The guide contains 161 numbered understandings. Presence is not evidence of full teaching depth or assessment coverage. This audit maps all understandings and reviews specific gaps; it does not certify complete mastery coverage.

The supplied file contains 26 standalone HTML documents: 24 topic lessons, one duplicated A2.1 lesson, and one additional Young’s Modulus quiz.

- **Whole site — structure:** The supplied file concatenates 26 standalone HTML documents. There are 24 distinct official topic lessons, a duplicate A2.1 lesson and an additional Young’s Modulus quiz. **Action:** Use one consistent application shell; keep one A2.1 lesson and retain the additional quiz.

- **B4.1, C4.1 — codes:** Production systems and Design for manufacture titles are labelled only 4.1. The A3.2 title also spaces A 3.2 inconsistently. **Action:** Use the official A/B/C topic prefixes in every curriculum location.

- **A3.4 — electronics-units:** The SI multiplier series p, n, μ, m, k, M, G, T is not explicitly taught. Quantities and symbols are only partly developed. **Action:** Add a prefix conversion reference and worked conversion challenge.

- **A3.4, B3.4 — electronics-symbols:** Circuit-symbol recognition and circuit construction are described in prose, with no displayed component-symbol set or circuit construction workspace in these lessons. **Action:** Provide an accessible visual symbol reference and practical drawing task.

- **B3.4 — logic-depth:** AND/OR/NOT output values are listed, but explicit Boolean notation and sequential logic with memory are not explained; learners are not asked to construct a full interactive truth table. **Action:** Add Boolean notation, combinational versus sequential explanation, and gated truth-table practice.

- **B3.4 — broken-exam:** Q2 has missing resistor values and blank choices; Q3 has missing LED voltage/current/supply data; Q4 omits pump voltage. Several teaching equations are empty. The HTML itself lacks these values, so this is not merely a rendering issue. **Action:** Retain the question intentions but rebuild them as clearly labelled repaired questions with stated numbers and worked solutions.

- **B3.4 — citation-artifacts:** Literal [cite: 1] tokens appear throughout electronics teaching and questions without a resolvable source. **Action:** Remove broken tokens and distinguish model classroom examples from verified commercial claims.

- **A3.4, B3.4, C3.2 — duration:** Lesson durations differ from the guide: A3.4 says approximately 4–5 hours (guide: 6); B3.4 says 16 hours (guide: 10); C3.2 says 3 hours (guide: 7). **Action:** Display the guide’s topic hours consistently; distinguish suggested activity timings.

- **C3.2 — lca-depth:** LCA has an overview, stage table and questions but limited quantitative inventory comparison and impact-category interpretation. It is among the shortest lessons despite a 7-hour allocation. Word count is a signal, not proof of insufficiency. **Action:** Add explicit material/energy inventory practice and multi-category trade-off evaluation.

- **C2.1 — glossary:** C2.1 contains no dedicated glossary section; the other 23 topic lessons have glossary sections, but full term completeness against the supplied glossary is not implied. **Action:** Populate every topic from the supplied official topic-specific glossary.

- **A3.4 — feedback:** The hand-dryer example treats rechecking hand presence as output feedback. Presence is an input; output feedback needs measurement of a controlled output quantity. **Action:** Use a thermostat measuring achieved temperature as the unambiguous closed-loop example.

- **C3.2 — lca-claim:** The lesson presents 12,274 litres of water per cotton T-shirt without an attributable source or boundary conditions. **Action:** Remove this unsupported universal figure; use explicitly fictional classroom inventory data.
